## Key Lessons (3 — carried forward into the fleet epics)

### L1: Editable installs defeat copy-based mutation testing — mutate in place
The mutmut false-0% was a genuinely non-obvious tooling trap: a mutation framework that copies
sources to a sandbox dir is invisible to a uv-workspace whose `[tool.uv.sources]` editable installs
resolve imports back to the original tree. cosmic-ray's VCS-in-place mutation is the only thing that
reaches the editable install. (Verify a non-zero smoke score before trusting any mutation harness.)

### L2: A quality gate is set at-or-below the current floor and ratcheted UP, never lowered silently
The mutation threshold (82) is the floor of the measured baseline. Lowering a gate to make a build
pass is a silent erosion; raising it as the suite improves is the ratchet. The same discipline
applies to cardinality baselines (Epic 13 L3) — a "magic number" gate is a one-way ratchet.

### L3: Build the enforcement gate BEFORE the thing it enforces
14-5 built `check_trace_id_required.py` and 15.2a built `check_tier_declarations.py` *before* the
fleet tools existed — so every Epic-15–19 tool was born under the gate, not retrofitted. A gate that
predates its subjects is enforced from line one; a gate added afterward leaves a backlog of
violations.
