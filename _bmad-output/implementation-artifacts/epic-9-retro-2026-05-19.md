## Key Insight

**Pass-N+1 catches partial-fix anti-pattern.**

When executor applies patches and sees green CI, it considers them closed. But "green CI + code merged" ≠ "finding actually fixed". Pass-2/pass-3 are secondary reviews that catch the gap between *compilation success* and *behavioral success*. The 3-pass cadence's value is precisely in this gap.

Corollary: **`[x]` checkboxes should never be aggregated when items have different status.** Pass-3 caught this same anti-pattern in pass-2's TM-E7 fix (marked `[x]` AND "deferred"). Self-similar bug across review depths.
